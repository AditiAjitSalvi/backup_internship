I want to apply a different logic than the one currently used in the system. Right now, when there are multiple tanks, the system uses a flow input load value to process items. Instead of using this load value, I want to implement a sequential processing logic.

For example, if I have three tanks containing Acid A, the logging station wagon should move items one by one to these tanks. After some processing time, the wagon should move the processed items from these three tanks to the next station.

The sequence should work like this:

Items are sent to Tank 1, Tank 2, and Tank 3 sequentially.

When Tank 1 completes its processing time, its items should move to the next station.

The same rule should apply to Tank 2 and Tank 3 once their processing time is completed.

Another important factor in this process is criticality:

If the criticality is high, the item must be moved from the acid tank immediately after its processing time.

If the criticality is low, the item can remain in the tank longer and be moved later.

However, keeping low-criticality items in the acid tank must not negatively affect the item quality or the process.
